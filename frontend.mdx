# Frontend

The frontend provides the user interface for interacting with the platform.

## Responsibilities

The frontend should:

- Present information clearly.
- Collect and validate user input.
- Display loading and error states.
- Hide actions that are unavailable to the user.
- Send requests to the backend.
- Display successful results.

## Security note

Hiding a button in the frontend improves usability, but it does not replace backend authorization.

## Recommended user experience

Each important action should provide:

- A clear label
- Required-field guidance
- A loading indicator
- A success message
- A useful error message
- A recovery action
