Rejesha Green helps teams manage users, records, roles, and operational workflows through a secured application platform.

This documentation explains how the platform works, how to develop changes safely, and how to deploy and verify those changes.

<Note>
  Documentation marked **Verified** reflects the current implementation or repository configuration. Content marked **Planned** or **Assumption** requires confirmation before implementation or operational use.
</Note>

## Intended users

This documentation primarily supports:

- Developers building or maintaining the platform
- System administrators managing environments and access

It also provides useful context for:

- Technical support teams
- Business analysts
- Project stakeholders

## Main capabilities

The platform includes:

- User authentication
- Role-based access control
- Record management
- Backend API services
- Web user interface
- Data storage
- Deployment and operational processes

Confirm each capability against the current implementation before treating it as verified.

## How to use this documentation

### New to the platform

Start with the [Quickstart](/quickstart) to set up the documentation workspace, then read the [Architecture](/architecture) page.

### Developing a change

Review the [Backend](/backend), [Frontend](/frontend), and [Security](/security) pages. Then follow the [Development workflow](/development-workflow).

### Testing a change

Use the [Testing](/testing) guide to verify success cases, failures, permissions, and regressions.

### Deploying a change

Follow [Deployment](/deployment), then use [Troubleshooting](/troubleshooting) if the result is not as expected.

### Looking up technical details

Use the [API reference](/api-reference), [Data model](/data-model), and [Glossary](/glossary).
