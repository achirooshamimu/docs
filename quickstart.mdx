This guide explains how a developer can find the Rejesha Green technical documentation, understand the system structure, and contribute documentation updates.

## Prerequisites
- Access to the `chirooshamimu/docs GitHub repository
- GitHub access to the main branch
- A modern web browser
- Basic familiarity with Markdown or MDX
- Permission to create or review documentation changes

## Explore the documentation
1. [System Overview](/overview) — understand the platform purpose and capabilities.
2. [System Architecture](/architecture) — review the platform components and documentation delivery workflow.
3. [Frontend](/frontend) — understand the presentation layer.
4. [Backend](/backend) — understand the application and API layer.
5. [Security Architecture](/security) — review authentication, authorization, and security controls.
6. [Deployment](/deployment) — understand how changes move from GitHub to the live site.
7. [Developer Guide](/developer-guide) — follow the development and contribution guidance.
